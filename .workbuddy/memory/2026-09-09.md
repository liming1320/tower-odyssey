## 14. 经典模拟器·原版 ROM（EmulatorJS 内嵌）
**用户需求**：要内嵌模拟器跑原版魂斗罗/坦克大战，参考 yikm / dos.lol / 80joy 那种体验

**实现**：
- `public/js/minigames/emulator.js`：EmulatorJS 引擎（开源 CDN）+ ROM 管理器
  - 9 个核心：nes / snes / gb / gba / segaMD / n64 / psx / dosbox / arcade
  - 扩展名自动判核心（`.nes`→FC），zip/7z 显示 9 选 1 核心选择器
  - ROM 存 IndexedDB（`tower-roms.roms`），仅本机浏览器；不支持时降级内存
  - 播放：iframe srcdoc 隔离 + blob URL 传 ROM 给 EmulatorJS
  - 拖放支持、`?v=20260909l`
- 注册：`MiniGames.emulator`（LEVELS 50 占位 / ENDLESS 自由玩）+ views/minigames.js 加 `sc('emulator', ...)` 卡片 + launch() 加 emulator 特殊分支（不走 50 关框架）
- 截图：`tools/shots/emu-{manager,imported,playing,corepick}.png`
- 端到端冒烟：`tools/smoke-emulator.js`（19/19 通过 — 包括 CDN 真实加载 EmulatorJS 后 canvas 创建）

**合规边界**：
- 模拟器本身（EmulatorJS）开源，可嵌入
- **ROM 文件由玩家自己导入**（个人合法持有的卡带备份），我不会从网上下载/分发任何 ROM —— 那是版权材料，不分平台分发都不可
- 用户反馈「这是自用的」也成立，但助手端不能成为盗版分发节点
