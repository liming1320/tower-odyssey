## 9. 2048 鼠标支持 + 美术重做（第五批需求）

### 9.1 用户反馈
- 进去点鼠标都没反应 → PC 完全无响应
- 图片都挺难看 → 上一版 Canvas 手绘妖怪太简陋

### 9.2 鼠标支持
- **bug 根因**：旧版只绑 `keydown`（键盘）+ `touchstart/touchend`（触屏），PC 鼠标完全无事件
- **修复**：
  - 加 `mousedown`（canvas 局部）+ `mouseup`（window 全局，防拖出释放丢失）
  - 拖拽阈值 22px（避免点击误触），横向位移 → L/R，纵向 → U/D
  - 键盘加 WASD 键位支持（小写 + Shift 大写都兼容）
  - `e.key.toLowerCase()` 防 Shift 输入法冲突

### 9.3 美术全面重做（emoji 方案）
- **决策**：弃用 Canvas 手绘 11 个 draw* 函数，改用系统彩色 Emoji（Segoe UI Emoji / Apple Color Emoji / Noto Color Emoji 降级链），理由：① 系统 emoji 是高质量美术资源 ② 风格绝对统一 ③ 微信小游戏主流做法 ④ Q 版可爱辨识度极高

- **同 emoji 不同色**：靠格子底板渐变色区分（L1/L4 绿、L2/L5 蓝、L3 黄、L6 红、L7/L10 橙、L8 紫、L9 棕、L11 深紫）
